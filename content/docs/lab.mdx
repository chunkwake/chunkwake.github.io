`chunkwake-lab` — отдельный бинарник для сквозных проверок и замеров. Он поднимает Chunkwake и настоящий `server.jar` рядом, подключает ботов и сравнивает поведение, MSPT, TPS и память.

Лаборатория не входит в релизный сервер: это инструмент разработки и проверки.

## Сборка

```bash
cargo build -p chunkwake-lab
cargo build --release -p chunkwake-server
```

Путь к релизной сборке (`target/release/chunkwake`) передаётся в `--chunkwake`: на нём идут замеры, потому что debug-сборка искажает MSPT.

## TUI

Запустите `target/debug/chunkwake-lab` без аргументов:

```bash
chunkwake-lab
```

По умолчанию выбран режим `Compare` — один сценарий на обоих серверах. Путь к Chunkwake уже указывает на релизную сборку.

- `↑` / `↓` — выбор поля, `←` / `→` — варианты и числа;
- `Enter` — редактировать путь или переключить флаг;
- `Tab` — сразу к строке «Start test»;
- поля нагрузки видны только в режиме `Bench`.

Прогресс Chunkwake и ванили показан в двух колонках.

## Режимы

| Режим | Что делает |
|---|---|
| `Compare` | один сценарий на Chunkwake и ванили, отличия сверяются с ожидаемыми |
| `Smoke` | сценарий только на Chunkwake, без ванили |
| `Bench` | нагрузка с заданным числом ботов и повторов на обоих серверах |

## Команды

```bash
chunkwake-lab smoke --chunkwake ./target/release/chunkwake --jar ./server.jar
chunkwake-lab compare --chunkwake ./target/release/chunkwake --accept-vanilla-eula
chunkwake-lab bench --chunkwake ./target/release/chunkwake \
  --profile movement --bots 20 --duration 30 --accept-vanilla-eula
chunkwake-lab bench --chunkwake ./target/release/chunkwake \
  --profile all --bots 10 --warmup 5 --duration 10 --repetitions 1
```

В PowerShell используйте `target\debug\chunkwake-lab.exe` и `target\release\chunkwake.exe`.

`--jar` необязателен: без него лаборатория скачает `server.jar` по манифесту Mojang в `target/chunkwake-lab/cache/26.3/` и проверит размер и SHA-1. Если указанный файл отсутствует, он тоже будет скачан.

Java выбирается в порядке `--java PATH` → `CHUNKWAKE_JAVA` из окружения или `.env` → `java` из `PATH`. Для Minecraft 26.3 нужна Java 25 или новее; лаборатория проверяет её до запуска.

## Профили нагрузки

| Профиль | Нагрузка |
|---|---|
| `join-burst` | одновременный вход всех ботов |
| `movement` | движение по кругу |
| `exploration` | переход между чанками |
| `redstone` | 64 лампы и 64 провода на 128 переключаемых опорах |
| `cows` | 2500 коров в сетке 50 × 50 |
| `all` | проверка поведения и сохранения, затем все пять профилей |

Каждый профиль получает отдельный мир. `--repetitions` задаёт число повторов; полная проверка поведения выполняется один раз.

## Отчёт

Каждый прогон создаёт каталог `target/chunkwake-lab/<id>/`:

- `report.html` — графики, проверки и поиск по журналам;
- `report.md` — таблицы;
- `report.json` — данные для CI;
- полные логи обоих серверов.

ECharts для графиков загружается с CDN, поэтому для отрисовки нужен интернет. Таблицы, данные и журналы встроены в HTML и остаются доступными.

`Compare` показывает известные отличия из `crates/lab/expected-differences.json` вместе с причиной. Новое отличие или ошибка сценария дают код выхода `1`; неверные аргументы или ошибка подготовки — `2`.

## Полезные флаги

| Флаг | Что делает |
|---|---|
| `--work-dir PATH` | меняет каталог прогонов и кэшей |
| `--generated-cache PATH` | готовые данные Chunkwake, ускоряет прогоны |
| `--keep-worlds` | сохраняет тестовые миры после прогона |
| `--java PATH` | явный путь к Java |
| `--accept-vanilla-eula` | явное согласие с EULA Minecraft для ванильного сервера |

Первый сравнительный запуск требует `--accept-vanilla-eula`; выбор запоминается в рабочем каталоге. Перед согласием прочитайте [Minecraft EULA](https://www.minecraft.net/en-us/eula).

## Как читать результат

Скорость сама по себе не доказывает совместимость. Настройки мира, которые Chunkwake пока не применяет, нельзя считать эквивалентными ванили, а различия в поведении важнее разницы в MSPT. Поэтому `Compare` проверяет и поведение, и сохранение, а `Bench` отвечает только на вопрос «сколько стоит тик».

Цифры с этого стенда — на странице [замеров](/ru/benchmarks).
