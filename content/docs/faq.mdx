## Это можно ставить на рабочий сервер?

Chunkwake в ранней стадии. Сначала сделайте резервную копию и проверьте сервер на тестовом клоне. Что уже готово, а что нет — в [фич-матрице](/ru/docs/feature-matrix).

## Обычные плагины Paper работают?

Да. Chunkwake запускает `plugins/*.jar`, читает `plugin.yml` и `paper-plugin.yml`, отдаёт события в порядке Paper и планировщики Folia. Плагины, которые обращаются к NMS, CraftBukkit или Netty, проверяйте по одному. Для плагинов нужна Java 25+.

## Нужна ли Java для самого сервера?

Нет. Ядро — один бинарник с данными игры и API плагинов. Java 25+ нужна только для запуска плагинов. Для сборки данных из `server.jar` нужен JDK 21+.

## Можно перенести мир, плагины и настройки?

Да. Anvil-миры, `level.dat`, `server.properties` и плагины переносятся. Пошаговый порядок, проверки и откат — в [миграции](/ru/docs/migrating).

## Чем это отличается от Folia?

В Folia обычные плагины отключаются без `folia-supported`. В Chunkwake планировщики Folia доступны всем плагинам, а региональная модель не навязывается тем, кто её не ждёт. Код, который рассчитывает на один главный поток, всё равно нужно проверять.

## Насколько он быстрее?

На стенде проекта запуск занимает 0.6–0.9 с против 6.6–11.4 с у ванили, а вход 20 ботов даёт p95 11–26 мс против 845–860 мс. Цифры зависят от мира, плагинов и железа. Замеры и оговорки — в [бенчмарке](/ru#benchmark) и [docs/perf.md](https://github.com/chunkwake/core/blob/ver/26.3/docs/perf.md).

## Где взять сборку?

Публичного релиза пока нет. Сервер собирается из исходников или берётся артефактом CI. Команды — на [странице загрузки](/ru/download).

На [странице поддержки](/ru/support) есть адреса для криптовалюты. Других способов пока нет.
